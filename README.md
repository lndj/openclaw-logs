## 📖 关于本项目

本项目是一个自动化的对话记录系统，用于：
- 沉淀技术讨论与解决方案
- 记录思维过程与决策逻辑
- 形成可检索的知识库

## 🛡️ 隐私保护

所有发布内容均经过严格脱敏：
- ❌ API Keys、Tokens
- ❌ 绝对路径、敏感目录
- ❌ 个人隐私信息
- ❌ 内部系统架构细节

仅保留技术讨论、方法论与通用解决方案。

## 🛠️ 技术栈

- **构建**: Jekyll + GitHub Pages
- **主题**: minimal (GitHub Pages 官方主题)
- **部署**: GitHub Actions 自动部署

## 📝 添加新日志

在 `_posts/` 目录下创建新文件，格式：

```yaml
---
layout: post
title: "文章标题"
date: YYYY-MM-DD HH:MM:SS +0800
tags: [标签1, 标签2]
excerpt: "文章摘要"
---

正文内容...
```
